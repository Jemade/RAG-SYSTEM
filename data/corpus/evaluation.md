# Evaluation policy — current
Factual answers use exact match after case, punctuation and whitespace normalization. Open-ended answers use an LLM judge with a reference and rubric. Ragas faithfulness checks claims against retrieved contexts. Retrieval recall measures coverage of relevant sources. Mean reciprocal rank measures position of the first relevant result. Skipped judge results must remain unscored, never counted as passes. Holdout questions must not be used for tuning. The release correctness threshold is 0.85. A missing relevant source is a retrieval failure; an unsupported answer with adequate context is a generation failure.
